「あ、おじいちゃん。AIがアケタロウのスケジュールと勝手にすり合わせしてくれたから、午後から遊びに行ってくるね。ついでに今、俺のスマホがローカルで抽出して創ってくれた『今日の俺用ニュース』見てたんだけどさ」

「ハハ、当時の人はそれが『客観的なニュース』だって信じてたんだよ。そういえば、動画や音楽だって昔は全部有料で売られていたんだ」

「え？ 待って、意味がわからないんだけど。『情報』でしょ？ コピーしたって元のデータが消えたり減ったりして失われるわけじゃないのに、なんでお金なんて求めるの？」

「当時は著作権法っていう法律があってね。クリエイターが作った作品を勝手に複製して配っちゃいけないルールだったんだよ。欲しい人はお金を払って買うのが当たり前だったんだ」

「ええ……？ 自分が好きで創った音楽なら、聴いた人が勝手に投げ銭して支援したりすればいいだけじゃん。内発的な動機じゃなくて、法律の力で強制的に金取ってたの？ それじゃあ、タイトルだけで中身スカスカの情報でも、買わせてしまえば稼ぎ放題だったってこと？」

「まあ、実際そういう商売もあったなぁ……（笑）」

「うわっ、マジで……？ なにそれ、ちょっと信じられない。だってさ、そもそも人が何かを表現するのって、根本的にはただの自己満足じゃん。自分が世界に向けて発信したいから、勝手に出してるだけでしょ？」

「まあ、昔のクリエイターも『表現したい』『誰かに伝えたい』っていう熱意は同じだったと思うよ。ただ、それを『商品』として、物理的なモノと同じように扱っていたんだ」

「いやいや、情報はモノとは全然違うじゃん。相手が自由に発信したものを、こっちがただ聞いて、自分の脳内で勝手に解釈して取捨選択してるだけだよ？ それって、そこら辺でしてる普通の会話と同じでしょ。道端で誰かが急に歌い出したのを偶然聞いちゃったら『はい、今俺の情報を脳に入れたからお金払ってね』って言われるようなもんじゃん」

「確かに、道端で聴いた歌にお金を請求されるような理不尽さはあるな。でも当時はね、その歌を作るために削った時間や機材代を回収するには、データそのものを囲い込んで有料で配るしかないと信じられていたんだよ」

「ふうん……すごく筋が通らない稼ぎ方だね。今なら、お金が必要なときは、誰かから『こういうのを作って！』って頼まれるか、事後に寄付される（求められていて行われた情報の創造だと暗示的に示す）かで、その制作っていう作業に対してお金をもらって、依頼した人と創る人が一緒になって『こういうのが欲しかった！』って喜んでいるけど、その部外者にとっては、頼まれてもいないデータを勝手に作っておいて、後から通りすがりの人に『複製したんだからお金払え』『俺が楽しくお絵描きしたんだから創作費払え』って一方的に請求するのって、仕組みとしておかしくない？」

「ハハ、お前たちの世代から見ればそうだろうな。でも昔は、そうやって『完成したデータの複製権を売ること』で生活するのがプロのクリエイターだったんだよ」

「へえー……でも、それだと順番が逆じゃない？求めていた情報が取得できたかを検証するためには、情報を見なければならないから、後払いになるのが自然なのに、なんで昔は先にお金を要求してたの？」
